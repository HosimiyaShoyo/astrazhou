连接 GitHub

要能发文章和传图片，需要一把「只能改这一个仓库」的钥匙（Personal Access Token）。 它只保存在本机浏览器，不会发到任何地方去。

怎么拿这把钥匙：

  1. 打开 https://github.com/settings/personal-access-tokens/new
  2. Token name 填 blog-admin，Expiration 选 90 days 或 No expiration
  3. Repository access 选 Only select repositories → 勾 HosimiyaShoyo/astrazhou
  4. Permissions → Repository permissions → 找到 Contents → 选 Read and write
  5. 点 Generate token，复制那串 github_pat_...
